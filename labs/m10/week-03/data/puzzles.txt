## Round 1: Quotes or braces?

### 1 | Lesson A, "Braces freeze everything"
set block CORE
puts "Block: $block"
puts {Block: $block}

### 2 | Lesson A, "Double quotes: group, then substitute"
set chipName Lumen-1
set chipWidth 400
puts "$chipName is $chipWidth um wide"

### 3 | Lesson A, "Double quotes: group, then substitute"
set chipWidth 400
puts "Half width: [expr {$chipWidth / 2}] um"

### 4 | Lesson A, "Braces freeze everything"
set chipWidth 400
puts {Half width: [expr {$chipWidth / 2}] um}

### 5 | Lesson A, "Inside [ ], a new command starts"
set block SRAM
puts "Name in braces: {$block}"
