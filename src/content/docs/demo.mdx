## 5. GlossaryTerm

When Tcl does a <GlossaryTerm term="substitution" /> it first splits the line into <GlossaryTerm term="word">words</GlossaryTerm>, then runs one <GlossaryTerm term="command" />. In a layout, each <GlossaryTerm term="layer" /> is a separate sheet of the map. Tab to a term to see its tooltip.

## 6. WorkedExample

<WorkedExample
  code={`set width 4
set height 3
set area [expr {$width * $height}]
puts "Area is $area"`}
  notes={{
    1: 'set creates a variable named width and gives it the value 4.',
    2: 'The same for height.',
    3: 'Square brackets run expr first. The braces keep expr safe and fast.',
    4: 'Double quotes allow $area to be replaced by its value.'
  }}
/>

## 9. Trap

  fix={`set a 3

## 11. VersionNote

<VersionNote
  since="9.0"
  code86={`puts [expr {010}]`}
  expect86="8"
  code90={`puts [expr {010}]`}
  expect90="10"
>
A number that starts with a zero used to be read as octal. In Tcl 9 it is read as ordinary decimal. To write octal on both versions, use the `0o` prefix, as in `0o10`.
</VersionNote>
