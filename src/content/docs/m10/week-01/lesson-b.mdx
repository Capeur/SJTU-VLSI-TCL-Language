## A command is a row of words

Tcl cuts every command into <GlossaryTerm term="word">words</GlossaryTerm> at the spaces. One space or ten makes no difference. The first word is the command's name: it says what to do. The other words are its <GlossaryTerm term="argument">arguments</GlossaryTerm>: they say what to do it with.

In Lesson A, `puts "Size: 400 x 300 um"` had just two words: `puts` and the text. The double quotes keep the text together as one word, spaces and all.

<Diagram name="w01-command-words" alt="Two commands cut into word boxes. set chipWidth 400 has three words: set is the command name, chipWidth is argument 1 and 400 is argument 2. puts, followed by Size: 400 x 300 um in double quotes, has two words: puts is the command name, and the quoted text is argument 1, kept as one word by the quotes. The quote marks themselves are not part of the word." />

Both lines below print the same thing. The extra spaces in line 2 only separate the words; they are not part of any word.

<TclPlayground client:visible code={`puts "Lumen-1"
puts          "Lumen-1"`} />

## Variables: give a value a name

A <GlossaryTerm term="variable" /> is a named box that holds a <GlossaryTerm term="value" />. The command `set` puts a value into a box: `set chipWidth 400` means "put 400 in the box called chipWidth". If the box does not exist yet, `set` creates it.

To use the value, write a dollar sign in front of the name: `$chipWidth`. Before the command runs, Tcl replaces `$chipWidth` with 400. This works inside double quotes too.

<Diagram name="w01-variable-box" alt="Three steps from left to right. First, set chipWidth 400 puts 400 into a box labelled chipWidth. In the middle, the variable: a named box holding one value, 400. Last, puts dollar chipWidth: Tcl replaces dollar chipWidth with the value in the box, so puts prints 400. A note says that without the dollar sign, puts chipWidth just prints the word chipWidth." />

<WorkedExample
  code={`set chipName Lumen-1
set chipWidth 400
puts $chipName
puts "Width: $chipWidth um"`}
  notes={{
    1: 'Three words: set is the command, chipName and Lumen-1 are its two arguments. set stores Lumen-1 in a new variable called chipName. set prints nothing.',
    2: 'The same for the width. Now two boxes exist: chipName holds Lumen-1, chipWidth holds 400.',
    3: 'The $ asks for the value. Tcl replaces $chipName with Lumen-1, then puts runs and prints: Lumen-1',
    4: 'Inside double quotes, $chipWidth is still replaced by its value. Output: Width: 400 um'
  }}
/>

Run it. Then change 400 to 500 in line 2 and run it again: the output follows the variable.

<TclPlayground client:visible code={`set chipName Lumen-1

## A variable can change

A box holds one value at a time. A second `set` with the same name throws the old value away and stores the new one. Tcl runs the commands in order, so each `$` gives whatever the box holds at that moment.

<WorkedExample
  code={`set block CORE
puts "Now checking: $block"
set block SRAM
puts "Now checking: $block"`}
  notes={{
    1: 'The variable block holds CORE.',
    2: 'Output: Now checking: CORE',
    3: 'The box now holds SRAM. CORE is gone for good.',
    4: 'The same command as line 2, but the box holds something new, so the output is different: Now checking: SRAM'
  }}
/>

## Common traps

<Trap
  wrong={`set chipName Lumen-1
puts chipName`}
  output={`chipName`}
  fix={`set chipName Lumen-1
puts $chipName`}
  why="Without a $, chipName is just a word, and puts prints that word. The $ is what tells Tcl to look in the box. No error appears, so this trap is easy to miss: always check your output."
/>

<Trap
  wrong={`set chipWidth 400
puts "Width: $chipWidht um"`}
  error={`can't read "chipWidht": no such variable`}
  fix={`set chipWidth 400
puts "Width: $chipWidth um"`}
  why="A typo in the name asks for a box that does not exist. Tcl shows the name it could not find, so compare it letter by letter with your set line. Capitals count too: $ChipWidth is a different name from $chipWidth."
/>

<Trap
  wrong={`set chipWidth = 400`}
  error={`wrong # args: should be "set varName ?newValue?"`}
  fix={`set chipWidth 400`}
  why="In maths you write width = 400, but set takes a name and a value, just two arguments. With = it gets three. The message wrong # args means the wrong number of arguments, and Tcl shows the right form: set, a variable name, then the new value."
/>
