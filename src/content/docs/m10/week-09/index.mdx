A list finds things by position: element 0, element 1. This week your data gets names. A dict finds a value by its key, like `METAL1`, and keeps its keys in order. An array is a family of variables, perfect for counters, but it keeps no order at all, and that is this week's trap. In the lab you build the layer table of {chip.name}: the link between the names people use and the numbers a GDS file stores.

## Review these first

This week builds on three earlier lessons. If any of these feels shaky, spend five minutes on it before Lesson A:

- [Week 5, Lesson B](/SJTU-VLSI-TCL-Language/m10/week-05/lesson-b/): foreach with two variables. dict for works the same way, with a key and a value.
- [Week 6, Lesson B](/SJTU-VLSI-TCL-Language/m10/week-06/lesson-b/): nested lists and `split`. A record inside a dict is the same idea, and the lab splits `4.0` at the dot.
- [Week 7, Lesson B](/SJTU-VLSI-TCL-Language/m10/week-07/lesson-b/): `upvar`. A proc that works on an array gets the array's name and uses upvar.
