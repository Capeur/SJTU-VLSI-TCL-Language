## Goal

**Build the layer table of {chip.name}, look one layer up, and count the shapes of a small layout on each layer.**

Why it matters for chips: a <GlossaryTerm term="gds">GDS</GlossaryTerm> file stores numbers, not names, so every layout tool keeps a table that links the two. In M30 you will draw real shapes with layer numbers like these, and in M40 you will count and check the shapes of whole layouts. This lab builds the table once, with the tools of this week.

## What you'll practise

- [Lesson A: dict, a table of names and values](/SJTU-VLSI-TCL-Language/m10/week-09/lesson-a/): `dict keys`, `dict for`, nested `dict set` / `dict get`, `dict exists`.
- [Lesson B: array, and choosing dict or array](/SJTU-VLSI-TCL-Language/m10/week-09/lesson-b/): `incr count($layer)`, `lsort [array names …]`.
- [Week 6, Lesson B](/SJTU-VLSI-TCL-Language/m10/week-06/lesson-b/): `split` and `join`.

## Specification

- **Inputs.** The starter gives you three lines. **Keep them exactly as they are.** The checker changes the last two twice and runs your script again.
  - `set layerNumbers {…}` is a <GlossaryTerm term="dictionary">dict</GlossaryTerm>: each teaching layer, then its GDS number, `layer.datatype`. These are teaching numbers, not any factory's. In this course, <GlossaryTerm term="datatype" /> 0 means the purpose `drawing` for every layer.
  - `set shapeLayers {…}` gives the layer of each shape in a small layout, one element per shape. Some shapes may be on layers that are not in the table.
  - `set lookUp METAL1` is the layer whose record you print.
- **Output.** With these inputs, your script must print exactly:

<pre class="tc-code" tabindex="0">{expected.trimEnd()}</pre>

- **Line 1** lists the layers in table order.
- **Line 2** is the record of `lookUp`: `number`, `datatype` and `purpose`. If `lookUp` is not in the table, print `METAL3: not in the table` (with its name).
- **Then one count line per layer of the table, in table order**, even for a layer with 0 shapes: the name, the GDS number and the number of shapes. **Do not use the order of `array names` for this report:** it is not promised and may differ between Tcl versions. Walk the table with `dict for` instead.
- **The Unknown line** names each layer that is not in the table once, sorted, with `, ` between them; or `Unknown: none`.
- **The last line** gives the number of shapes, and how many of them are on unknown layers.
- Words, capitals and punctuation must match. Extra spaces are forgiven.

## Step by step

Press **Run** after every step, and compare your new lines with the specification.

1. **Names.** `dict keys $layerNumbers` gives the layers in table order.
2. **Records.** Start with `set layers [dict create]`. Walk `layerNumbers` with `dict for {name gds}`. Split `gds` at the dot, then `dict set` the fields `number`, `datatype` and `purpose` of the record `$name`.
3. **Look up.** If `dict exists $layers $lookUp`, read the three fields with `dict get` and print them. Otherwise print that it is not in the table.
4. **Count.** Set `count($name)` to 0 for every layer, with `dict for`. Then, for each shape: if its layer is in the table, `incr count($layer)`; if not, remember it with `set unknown($layer) 1` and count it as unknown.
5. **Report.** Walk `layerNumbers` again with `dict for`, and print one count line per layer.
6. **Unknown and totals.** `lsort [array names unknown]` gives the unknown layers once each, sorted. If that list is empty, print `Unknown: none`. Then print the totals.
