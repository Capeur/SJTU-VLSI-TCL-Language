So far your scripts mostly worked with numbers and lists. This week they work with text, one character at a time. Layer names of {chip.name} are typed by people, so they come with stray spaces, odd capitals and typos. You will measure text, cut a name like `POLY_pin` into a layer and a purpose, clean it, test it against a pattern, and finally print reports with neat, rounded columns.

## Review these first

This week builds on three earlier lessons. If any of these feels shaky, spend five minutes on it before Lesson A:

- [Week 3, Lesson A](/SJTU-VLSI-TCL-Language/m10/week-03/lesson-a/): braces stop substitution. A pattern like `{[A-Z]*}` must be in braces, or Tcl runs the brackets as a command.
- [Week 6, Lesson A](/SJTU-VLSI-TCL-Language/m10/week-06/lesson-a/): `lrange` and `lsearch`. `string range` counts the same way, and `string first` also gives −1 for "not found".
- [Week 6, Lesson B](/SJTU-VLSI-TCL-Language/m10/week-06/lesson-b/): `split` and `join`, which cut text into a list. This week you cut text without making a list.
