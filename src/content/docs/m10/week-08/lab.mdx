## Goal

**Clean a list of layer names that people typed, check each one, and report how many are valid.**

Why it matters for chips: a teammate collected the layer names used in the settings files of {chip.name}. Some have spaces around them, some use the wrong capitals, one has a dash instead of an underscore, and a few name a layer or a <GlossaryTerm term="layer-purpose">purpose</GlossaryTerm> that does not exist. Before anyone trusts those files, your script cleans every name the same way and flags the bad ones.

## What you'll practise

- [Lesson A: Strings, character by character](/SJTU-VLSI-TCL-Language/m10/week-08/lesson-a/): `string trim`, `string first`, `string range`, `toupper`, `tolower`.
- [Lesson B: Patterns, swaps and tidy numbers](/SJTU-VLSI-TCL-Language/m10/week-08/lesson-b/): `string match`, `string map`, `format`.
- [Week 6, Lesson A](/SJTU-VLSI-TCL-Language/m10/week-06/lesson-a/): `lsearch` and its −1.

## Specification

- **Inputs.** The starter gives you three lines. `set rawNames {…}` is the list of names as people typed them; `{ poly_drawing }` is one element with a space on each side. `set knownLayers {…}` lists the layers of {chip.name}. `set knownPurposes {drawing pin}` lists the purposes this check accepts. **Keep these three lines exactly as they are.** The checker changes their values twice and runs your script again.
- **Our cleaning rules.** These are the rules of this course, for this lab. A real design tool has its own rules, and most tools would simply reject a badly typed name. Apply them to each name, in this order:
  1. Trim the spaces at both ends, then replace every `-` with `_`.
  2. If the name has no `_`, it has no purpose. Print `BAD`, the trimmed name **in capitals**, and `: no purpose`. So ` metal2 ` gives `BAD METAL2: no purpose`.
  3. Otherwise, cut the name at its **first** `_`. The layer is the part before it, in capitals; the purpose is the part after it, in lower case. The clean name is `LAYER_purpose`.
  4. If the layer is not in `knownLayers`, print `BAD <clean name>: unknown layer <layer>`. Else, if the purpose is not in `knownPurposes`, print `BAD <clean name>: unknown purpose <purpose>`. Else print `OK` and the clean name.
- **Output.** One line per name, in the order of `rawNames`, then a summary line. The share is 100 × valid ÷ total, rounded to 1 decimal. With the starter's inputs, your script must print exactly:

<pre class="tc-code" tabindex="0">{expected.trimEnd()}</pre>

- Words, capitals and punctuation must match. Extra spaces are forgiven, so `OK  ` with two spaces (to line up with `BAD`) and `OK ` with one are both fine.

The purposes `drawing` and `pin` are teaching purposes. Real tools have many more.

## Step by step

Press **Run** after every step, and compare your new lines with the specification. Steps 2 to 4 all go inside the loop of step 1.

1. **Clean.** Put `set valid 0` before the loop. Then `foreach raw $rawNames {…}`: set `name` to the trimmed name, then to `string map {- _} $name`.
2. **No purpose.** Test `string match *_* $name`. If it gives 0, print the BAD line with `string toupper $name`.
3. **Cut.** Otherwise, find the first `_` with `string first`, cut out the layer and the purpose with `string range`, and change their case. Glue them back with `"${layer}_$purpose"`.
4. **Check.** Use `lsearch` on `knownLayers`, then on `knownPurposes`. −1 means "not in the list". On an OK line, `incr valid`.
5. **Summary.** After the loop, compute the share with `100.0` and print it with `format %.1f`, followed by `%`.

## Check your work

- **Browser:** press **Check my work** in the Playground tab.
- **Terminal:** in the lab folder, run `tclsh tests/test.tcl`.

You get one line per test:

- `PASS`: this part is right.
- `FAIL`: you see what was expected, what your script printed, often a hint, and which lesson section to revisit.
- `TODO`: you have not done this step yet.
- `NOTE`: the checker could not run a test. It tells you which input line to put back.

The last line is `RESULT: PASS 10/10` when everything is right. The last two tests change the inputs: first a lower-case name, a name with no purpose and a share that needs rounding, then other purposes and a name with two underscores. They pass only if every line comes from the inputs.
