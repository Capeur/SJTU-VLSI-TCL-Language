## A list is words in a row

A <GlossaryTerm term="list" /> is one value that holds many values in order, separated by spaces. Each value in it is an <GlossaryTerm term="element" />. You can write a list in braces: `set blocks {CORE SRAM ADC SENSOR PADS}`. The braces make it one word for set, exactly as in Week 3.

Two commands read a list. `llength` counts its elements. `lindex` picks one element by its <GlossaryTerm term="index" />, its position number. **Tcl counts from 0**: the first element has index 0, the second has index 1. The word `end` means the last element, so you do not have to count.

<Diagram name="w05-list-boxes" alt="The list CORE SRAM ADC SENSOR PADS drawn as five boxes in a row, numbered 0, 1, 2, 3 and 4 underneath; 4 is also called end. Counting starts at 0. Below: llength of blocks gives 5; lindex blocks 0 gives CORE; lindex blocks 2 gives ADC; lindex blocks end gives PADS." />

<WorkedExample
  code={`set blocks {CORE SRAM ADC SENSOR PADS}
puts [llength $blocks]
puts [lindex $blocks 0]
puts [lindex $blocks 2]
puts [lindex $blocks end]`}
  notes={{
    1: 'One variable, five elements. The braces keep the five names together as one word for set.',
    2: 'llength counts the elements. Output: 5',
    3: 'Index 0 is the first element. Output: CORE',
    4: 'Index 2 is the THIRD element: 0, 1, 2. Output: ADC',
    5: 'end is the last element, however long the list is. Output: PADS'
  }}
/>

Run it. Then change the 2 to 4, and then to 5. What does lindex give for an index that does not exist?

## Rectangles as lists

Every block of {chip.name} is a rectangle, and two corners describe it: the bottom-left corner (x1, y1) and the top-right corner (x2, y2). Each <GlossaryTerm term="coordinate" /> is a distance in µm from the chip's bottom-left corner. Four numbers make one list: CORE is `{20 20 220 180}`.

The width is x2 − x1, and the height is y2 − y1. With lindex, x1 is index 0, y1 is index 1, x2 is index 2 and y2 is index 3.

When the numbers are in variables, build the list with the `list` command: `list $x1 $y1 $x2 $y2`. Braces would freeze the dollar signs, as you saw in Week 3.

<Diagram name="w05-rect-corners" alt="The CORE block drawn on x and y axes from the chip's corner at 0, 0. Its bottom-left corner is x1, y1 equal to 20, 20 and its top-right corner is x2, y2 equal to 220, 180. An arrow across shows width equals x2 minus x1 equals 200; an arrow up shows height equals y2 minus y1 equals 160. Next to it, the list 20 20 220 180 with index 0 x1, index 1 y1, index 2 x2 and index 3 y2: one value holds the whole rectangle." />

<WorkedExample
  code={`set x1 20
set y1 20
set x2 220
set y2 180
set core [list $x1 $y1 $x2 $y2]
puts "CORE: $core"
set width [expr {[lindex $core 2] - [lindex $core 0]}]
set height [expr {[lindex $core 3] - [lindex $core 1]}]
puts "Width: $width um, height: $height um"`}
  notes={{
    1: 'The bottom-left corner of CORE: x1 …',
    2: '… and y1.',
    3: 'The top-right corner: x2 …',
    4: '… and y2.',
    5: 'list builds a list from the four values. Tcl replaces each $ first, so core holds 20 20 220 180.',
    6: 'Output: CORE: 20 20 220 180',
    7: 'x2 is index 2 and x1 is index 0. expr runs the brackets inside its braces itself (Week 3). 220 - 20 = 200.',
    8: 'y2 is index 3 and y1 is index 1: 180 - 20 = 160.',
    9: 'Output: Width: 200 um, height: 160 um. In Week 23 you will draw rectangles like this one in a real layout.'
  }}
/>

## Common traps

<Trap
  wrong={`set blocks {CORE SRAM ADC SENSOR PADS}
puts "Last block: [lindex $blocks 5]"`}
  output={`Last block:`}
  fix={`set blocks {CORE SRAM ADC SENSOR PADS}
puts "Last block: [lindex $blocks end]"`}
  why="Five elements have the indexes 0 to 4. Index 5 is past the end, and lindex gives an empty value instead of an error, so the mistake is silent. Use end for the last element, or count from 0."
/>

<Trap
  wrong={`set x1 20
set y1 20
set rect {$x1 $y1 220 180}
puts [lindex $rect 0]`}
  output={`$x1`}
  fix={`set x1 20
set y1 20
set rect [list $x1 $y1 220 180]
puts [lindex $rect 0]`}
  why="Braces freeze everything inside, so the list holds the text $x1, not the number 20. To build a list from variables, use the list command: Tcl replaces each $ first, then list keeps the values."
/>

<Trap
  wrong={`set blocks {CORE SRAM ADC SENSOR PADS}
puts [llength blocks]`}
  output={`1`}
  fix={`set blocks {CORE SRAM ADC SENSOR PADS}
puts [llength $blocks]`}
  why="Without the $, llength receives the word blocks itself: a list with one element. The $ asks for the value of the variable, the list of five names."
/>
