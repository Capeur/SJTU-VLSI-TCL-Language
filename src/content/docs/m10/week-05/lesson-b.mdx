## foreach: visit every item

`foreach layer $layers {body}` runs the body once for every element of the list. On each pass, it first puts the next element in the <GlossaryTerm term="loop-variable">loop variable</GlossaryTerm>, here `layer`. When the list runs out, the loop ends.

foreach is a loop, like while, but simpler: there is no condition and no incr to forget. It cannot run forever, because every list has an end. You can still keep a counter of your own, like `number` below, when you need one.

<Diagram name="w05-foreach" alt="The list of layers drawn as boxes: ACTIVE, POLY, CONTACT, METAL1 and 3 more. An arrow goes from each box to one pass of the loop: pass 1, layer equals ACTIVE; pass 2, layer equals POLY; pass 3, layer equals CONTACT. On every pass, foreach puts the next element in the loop variable, then runs the body. After the last element, the loop ends: no counter and no condition are needed." />

<WorkedExample
  code={`set layers {ACTIVE POLY CONTACT METAL1 VIA1 METAL2 TEXT}
set number 1
foreach layer $layers {
    puts "Layer $number: $layer"
    incr number
}`}
  notes={{
    1: 'The seven layers of Lumen-1, from the bottom of the chip to the top.',
    2: 'Our own counter, to number the lines. foreach does not need it.',
    3: 'The loop variable is layer. On pass 1 it holds ACTIVE, on pass 2 POLY, and so on.',
    4: 'Output on pass 1: Layer 1: ACTIVE',
    5: 'The counter goes up by one on every pass.',
    6: 'After pass 7, with TEXT, the list has run out, so the loop ends. Last line: Layer 7: TEXT'
  }}
/>

## Several variables at once

Give foreach a list of variable names in braces, and it takes that many elements on every pass. Here is a table of block sizes as one flat list, where every three elements belong together: a name, a width and a height.

`foreach {name width height} $blockSizes {…}` takes CORE, 200 and 160 on the first pass, then SRAM, 140 and 160, and so on. Check that the list length is a multiple of the number of variables: 15 elements and 3 variables give 5 passes.

<Diagram name="w05-foreach-groups" alt="foreach with three loop variables, name, width and height, over a flat list of block sizes. The list is cut into groups of three: CORE 200 160, SRAM 140 160, ADC 120 80, and so on. Pass 1 sets name to CORE, width to 200 and height to 160; pass 2, SRAM, 140, 160; pass 3, ADC, 120, 80. 15 elements, 3 per pass: 5 passes, one per block." />

<TclPlayground client:visible code={`set blockSizes {CORE 200 160 SRAM 140 160 ADC 120 80 SENSOR 100 80 PADS 100 80}
foreach {name width height} $blockSizes {
    puts "$name: [expr {$width * $height}] um2"
}`} />

## lappend: grow a list

`lappend tall CORE` adds CORE to the end of the list in the variable `tall`. Like `set` and `incr`, lappend takes the variable's name, with no `$`, because it changes what is in the box. If the variable does not exist yet, lappend creates it.

The usual pattern: start with an empty list, `set tall {}`, then lappend inside a loop whenever you find something. After the loop, llength tells you how many you found.

<WorkedExample
  code={`set blockSizes {CORE 200 160 SRAM 140 160 ADC 120 80 SENSOR 100 80 PADS 100 80}
set tall {}
foreach {name width height} $blockSizes {
    if {$height > 100} {
        lappend tall $name
    }
}
puts "Tall blocks: $tall"
puts "Count: [llength $tall]"`}
  notes={{
    1: 'Each block as name, width, height, all in one flat list.',
    2: 'An empty list, ready to collect names.',
    3: 'Three loop variables, so each pass takes one block: 5 passes.',
    4: 'Is this block more than 100 µm tall?',
    5: 'If so, add its name to the end of tall. No $ before tall: lappend needs the name.',
    6: 'The end of the if.',
    7: 'The end of the loop. Only CORE and SRAM are 160 µm tall; the others are 80.',
    8: 'Output: Tall blocks: CORE SRAM',
    9: 'Output: Count: 2'
  }}
/>

## Common traps

<Trap
  wrong={`set tall {}
lappend $tall CORE
puts "Tall: $tall"`}
  output={`Tall:`}
  fix={`set tall {}
lappend tall CORE
puts "Tall: $tall"`}
  why="lappend needs the variable's name. With $tall, Tcl first replaces it with its value, the empty list, so lappend adds CORE to a variable with an empty name, and tall never changes. No error appears, so always check your output."
/>

<Trap
  wrong={`set blocks {CORE SRAM ADC}
foreach block blocks {
    puts "Block: $block"
}`}
  output={`Block: blocks`}
  fix={`set blocks {CORE SRAM ADC}
foreach block $blocks {
    puts "Block: $block"
}`}
  why="Without the $, foreach walks through the word blocks itself: a list with one element. So the body runs once, with the word blocks. foreach needs the list's value: $blocks."
/>

<Trap
  wrong={`foreach {name width height} {CORE 200 160 SRAM 140} {
    puts "$name is $width by $height um"
}`}
  output={`CORE is 200 by 160 um
SRAM is 140 by  um`}
  fix={`foreach {name width height} {CORE 200 160 SRAM 140 160} {
    puts "$name is $width by $height um"
}`}
  why="foreach takes three elements per pass, but the list has only five. On the second pass there is nothing left for height, so it is empty, and no error appears. Check that the list length is a multiple of the number of loop variables."
/>
