So far each variable held one value. This week one variable holds many: the {chip.blocks.length} block names of {chip.name}, its {chip.layers.length} layers, or the four corners of a rectangle. With lists and the foreach loop, the same few lines of code can check five shapes or five thousand. The rectangles you store this week are the ones you will draw for real in Week 23.
