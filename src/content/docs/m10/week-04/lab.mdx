## Goal

**Check one METAL1 <GlossaryTerm term="wire" /> against the minimum width, then count how many wires fit side by side in the gap between two blocks of {chip.name}.**

Why it matters for chips: a <GlossaryTerm term="design-rule">design rule</GlossaryTerm> check looks at millions of shapes and decides, for each one, whether it is OK. Routing tools, which draw the wires, ask the second question all the time: how many wires fit in this space? Both are an if and a loop at heart.

## What you'll practise

- [Lesson A: if, make a decision](/SJTU-VLSI-TCL-Language/m10/week-04/lesson-a/): comparisons, `if`, `elseif`, `else`.
- [Lesson B: Loops](/SJTU-VLSI-TCL-Language/m10/week-04/lesson-b/): `while`, `incr`, a counter.

## Specification

Between CORE and SRAM there is a strip of empty space: CORE ends at x = {core.x + core.w} µm and SRAM starts at x = {sram.x} µm. That is a {sram.x - core.x - core.w} µm <GlossaryTerm term="channel" />, where METAL1 wires can run from bottom to top.

- **Inputs.** The starter gives you five lines: `set wireName CLK`, `set wireWidth 2`, `set minWidth 3`, `set minSpace 2` and `set channelWidth 20`. All sizes are in µm. **Keep these five lines exactly as they are.** The checker changes their values three times and runs your script again, to test every branch of your if and every length of your loop.
- **Output.** With these inputs, your script must print exactly:

<pre class="tc-code" tabindex="0">{expected.trimEnd()}</pre>

- **Line 2, the result,** is one of three texts: `TOO NARROW` when the wire is narrower than `minWidth`, `OK, AT THE MINIMUM` when it is exactly `minWidth`, and `OK` when it is wider.
- **The tracks.** Each track is a wire of width `minWidth`. Every wire must stay at least `minSpace` away from CORE, from SRAM and from the next wire. x is measured from CORE's edge, and a track's x is its left edge. The first track starts at x = `minSpace`. A track fits only if `x + minWidth + minSpace` is not more than `channelWidth`.
- Words, capitals and units must match. Extra spaces are forgiven. These are teaching numbers: real chips use much thinner wires.

## Step by step

Press **Run** after every step, and compare your new lines with the specification.

1. **The wire line.** Print line 1 with `$wireName`, `$wireWidth` and `$minWidth` in it.
2. **The result.** Write an if with an elseif and an else. Each branch prints one of the three result lines. Then test it: change `wireWidth` to 3, then to 4, and press Run each time. Does the result change? Put it back to 2.
3. **The tracks.** Set `x` to `minSpace` and a counter to 0. Then write a while loop: while a track fits at `x`, add 1 to the counter, print the track line, and move `x` on by one track and one space.
4. **The count.** After the loop, print how many tracks fit.

## Check your work

- **Browser:** press **Check my work** in the Playground tab.
- **Terminal:** in the lab folder, run `tclsh tests/test.tcl`.

You get one line per test:

- `PASS`: this part is right.
- `FAIL`: you see what was expected, what your script printed, often a hint, and which lesson section to revisit.
- `TODO`: you have not done this step yet.
- `NOTE`: the checker could not run a test. It tells you which input line to put back.

The last line is `RESULT: PASS 9/9` when everything is right. The last three tests change the inputs: a wire exactly at the minimum, a channel where the last track fits exactly, and a channel with no room at all. They pass only if your script really decides and really loops. If your loop never ends, the checker stops it and tells you, instead of freezing.
