Until now you used the commands Tcl gave you. This week you make your own. A proc gives a piece of code a name, so you write it once and call it everywhere. You will write the two commands at the heart of the M10 capstone: `rectArea`, and `rectOverlaps`, which decides whether two blocks of {chip.name} clash. It follows one clear rule: in this course, blocks that touch count as a clash.

## Review these first

This week builds on three earlier lessons. If any of these feels shaky, spend five minutes on it before Lesson A:

- [Week 4, Lesson A](/SJTU-VLSI-TCL-Language/m10/week-04/lesson-a/): `<=`, `&&` and `if`. The touching rule is four comparisons joined with `&&`.
- [Week 4, Lesson B](/SJTU-VLSI-TCL-Language/m10/week-04/lesson-b/): the `for` loop. This week you put one for loop inside another.
- [Week 6, Lesson B](/SJTU-VLSI-TCL-Language/m10/week-06/lesson-b/): nested lists. The lab's floorplan is a list of `{name {x1 y1 x2 y2}}` pairs.
