## A list of rectangles

An element of a list can itself be a list. Then the outer list is a <GlossaryTerm term="nested-list">nested list</GlossaryTerm>. In Lesson A, each element was a pair. Here, each element is a whole rectangle, `{x1 y1 x2 y2}`.

To build one, start with an empty list and add each rectangle with `lappend rects [list 20 20 220 180]`. The list command makes the four numbers into ONE element.

To read it, give lindex more than one index. `lindex $rects 1` is the second rectangle. `lindex $rects 1 2` goes one level deeper: element 2 of the second rectangle, its x2. And `foreach rect $rects` takes one whole rectangle per pass.

<Diagram name="w06-nested" alt="A big box labelled rects holds two smaller boxes side by side. Box 0 holds CORE's corners 20 20 220 180; box 1 holds SRAM's corners 240 20 380 180, and inside box 1 the numbers are numbered 0 to 3. lindex rects 1 gives the whole box 1. lindex rects 1 2 first opens box 1, then takes its element 2: 380, SRAM's x2. llength rects is 2: two rectangles, not eight numbers." />

<WorkedExample
  code={`set rects {}
lappend rects [list 20 20 220 180]
lappend rects [list 240 20 380 180]
puts "Rectangles: [llength $rects]"
puts "SRAM: [lindex $rects 1]"
puts "SRAM's x2: [lindex $rects 1 2]"
foreach rect $rects {
    puts "Width: [expr {[lindex $rect 2] - [lindex $rect 0]}] um"
}`}
  notes={{
    1: 'An empty list, ready to hold rectangles.',
    2: 'list makes CORE’s four corners into one element, and lappend adds it.',
    3: 'The same for SRAM. rects now holds two elements.',
    4: 'Two rectangles, not eight numbers. Output: Rectangles: 2',
    5: 'Index 1 is the second element: a whole rectangle. Output: SRAM: 240 20 380 180',
    6: 'Two indexes: element 1, then its element 2, x2. Output: SRAM’s x2: 380',
    7: 'One whole rectangle per pass, in the loop variable rect.',
    8: 'x2 - x1, as in Week 5. Output: Width: 200 um, then Width: 140 um'
  }}
/>

## lmap: a new list from an old one

Often you want one new value for each element: the width of every rectangle, or the name of every pair. With foreach, you would start an empty list and lappend inside the loop. `lmap` does both for you.

`lmap rect $rects {body}` works like foreach, but it collects the result of the body on every pass and gives back the list of results. The body's last command gives the value to keep, so end it with `expr {…}` or `lindex …`, not with puts.

<TclPlayground client:visible code={`set rects {{20 20 220 180} {240 20 380 180} {20 200 140 280}}
set widths [lmap rect $rects {expr {[lindex $rect 2] - [lindex $rect 0]}}]
puts $widths
set names [lmap pair {{CORE 32000} {SRAM 22400}} {lindex $pair 0}]
puts $names`} />

## split and join: text and lists

Data often arrives as one line of text, with a <GlossaryTerm term="separator" /> character between the parts, like the commas in `ACTIVE,POLY,CONTACT`. `split $text ,` cuts the text at every comma and gives a list of the parts. You will read such lines from files in Week 13.

`join` does the opposite. `join $names ", "` glues the elements together into one piece of text, with `, ` between them. That makes reports easy to read.

<Diagram name="w06-split-join" alt="At the top, the text ACTIVE,POLY,CONTACT as one strip. split with a comma cuts it at each comma into a list of three boxes: ACTIVE, POLY, CONTACT. At the bottom, join with a comma and a space glues the three boxes back into one strip of text: ACTIVE, POLY, CONTACT. split turns text into a list; join turns a list into text." />

<WorkedExample
  code={`set text "CORE 20 20 220 180;SRAM 240 20 380 180"
set rows [split $text ";"]
puts "Rows: [llength $rows]"
puts [lindex $rows 1]
set names [lmap row $rows {lindex $row 0}]
puts [join $names ", "]`}
  notes={{
    1: 'One line of text: two blocks, each a name and four corners, with a semicolon between them.',
    2: 'Cut at every semicolon. The quotes stop Tcl from reading ; as the end of the command.',
    3: 'Two parts, so two rows. Output: Rows: 2',
    4: 'Each row is text with spaces, so it works as a list too. Output: SRAM 240 20 380 180',
    5: 'lmap takes element 0, the name, of every row. names holds CORE SRAM.',
    6: 'Glue the names with a comma and a space. Output: CORE, SRAM'
  }}
/>

## Common traps

<Trap
  wrong={`set rects {}
lappend rects 20 20 220 180
lappend rects 240 20 380 180
puts "Rectangles: [llength $rects]"`}
  output={`Rectangles: 8`}
  fix={`set rects {}
lappend rects [list 20 20 220 180]
lappend rects [list 240 20 380 180]
puts "Rectangles: [llength $rects]"`}
  why="lappend adds each of its values as a separate element. Four numbers become four elements, so two rectangles become eight numbers in one flat list. Wrap the four numbers with list: then lappend adds ONE element, the whole rectangle."
/>

<Trap
  wrong={`set layers [split "METAL1, VIA1, METAL2" ,]
puts "Second: <[lindex $layers 1]>"`}
  output={`Second: < VIA1>`}
  fix={`set layers [split "METAL1,VIA1,METAL2" ,]
puts "Second: <[lindex $layers 1]>"`}
  why="split cuts at the commas and nowhere else. The space after each comma stays in the next part, so the second element is ' VIA1', with a space in front, and it is no longer equal to VIA1. Here the text was ours to fix; Week 8 shows how to trim spaces off text you cannot change."
/>
